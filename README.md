## 📝 摘要![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/6a112bcbb9174dc6b61517cd488fc5fc.png)


航拍工地危险区域检测数据集，合计6398张450×600图像，包含板材、护栏、坑洞、水域、崖区5类工地危险源，提供YOLO、VOC、COCO三种标注，划分训练集5121张、验证集642张、测试集635张。适配无人机航拍巡检场景，用于工地安全隐患识别、智慧工地预警算法训练，兼容主流YOLO系列模型，适合科研实验与毕业设计。
